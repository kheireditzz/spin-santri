# Spin Santri

Aplikasi web modern untuk mengundi dan memutar nama santri secara acak, adil, dan presisi.

## Fitur
- Desain bersih bertema terang (*Clean White Theme*) responsif untuk mobile & desktop.
- Jarum penunjuk akurat 100% tepat mengarah ke nama santri pemenang.
- Pengaturan santri lengkap (Tambah, Edit nama, dan Hapus).
- Riwayat putaran lengkap mencatat Nama, Hari, Tanggal, dan Jam WIB.
- Animasi perayaan konfeti dan dialog hasil undian.
